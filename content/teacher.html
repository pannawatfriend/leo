Roblox จากศูนย์สู่การเผยแพร่

คอร์ส 8 คาบ พานักเรียนชั้นประถมศึกษาปีที่ 6 สร้างเกม Roblox ของตัวเองตั้งแต่ยังไม่มีบัญชี จนกดเผยแพร่เกมให้เพื่อนทั่วโลกเล่นได้จริงบนเว็บ Roblox

  • 8 คาบคาบละ 50–60 นาที
  • ป.6อายุ 11–12 ปี
  • เน้นสร้างแมป+ สคริปต์เบา ๆ แบบคัดลอกวาง
  • ผลงาน 1 เกมเผยแพร่จริงบน Roblox
01 · ภาพรวม

คอร์สนี้คืออะไร

นักเรียนแต่ละคน (หรือจับคู่) จะสร้าง เกมแนวผจญภัยข้ามด่าน (Obby) หนึ่งเกม โดยเรียนรู้การใช้ Roblox Studio การต่อบล็อก การจัดพื้นโลก การใส่จุดเกิด กับดัก จุดเซฟ ระบบเก็บเหรียญและนับคะแนน แล้วจบด้วยการกดเผยแพร่เกมขึ้นเว็บ Roblox ให้เป็นสาธารณะ

คอร์สออกแบบให้ ครูที่ไม่เคยเขียนโปรแกรม ก็สอนได้ สคริปต์ทุกชิ้นมีให้คัดลอกวางพร้อมคำอธิบายทีละบรรทัดในภาคผนวก นักเรียนจะได้ฝึกทักษะการออกแบบ การแก้ปัญหา และการทำงานเป็นขั้นตอน มากกว่าการท่องจำโค้ด

คอร์สนี้เหมาะกับใคร

  • นักเรียน ป.6 ที่ใช้คอมพิวเตอร์พื้นฐานได้ (เปิดโปรแกรม พิมพ์ ลากเมาส์ บันทึกไฟล์)
  • ไม่จำเป็นต้องเคยเล่น Roblox มาก่อน แต่ถ้าเคยเล่นจะช่วยให้เข้าใจเป้าหมายเร็วขึ้น
  • ครูผู้สอนไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรม

02 · เป้าหมาย

ผลลัพธ์การเรียนรู้

เมื่อจบคอร์ส นักเรียนจะสามารถ...

  1. ใช้งาน Roblox Studio — เปิดโปรเจกต์ ใช้หน้าต่าง Explorer และ Properties เคลื่อนกล้อง และบันทึกงานขึ้นคลาวด์ได้
  2. ก่อสร้างฉาก — สร้างและจัดวาง Part ปรับขนาด/หมุน/ย้าย เปลี่ยนสีและวัสดุ จัดกลุ่มเป็น Model และใช้เครื่องมือ Terrain ขึ้นภูมิประเทศได้
  3. เปลี่ยนฉากให้เป็นเกม — วางจุดเกิด (SpawnLocation) ใส่กับดัก จุดเซฟด่าน และระบบนับคะแนน/เหรียญ ด้วยสคริปต์สำเร็จรูป
  4. ออกแบบด่านที่เล่นสนุก — วางระดับความยาก จังหวะพัก และเส้นทางให้ผู้เล่นผ่านได้อย่างท้าทายแต่ไม่หงุดหงิด
  5. ทดสอบและแก้บั๊ก — เล่นทดสอบเกมตัวเอง รับฟีดแบ็กจากเพื่อน และแก้ไขจุดที่พัง
  6. เผยแพร่ผลงาน — ตั้งชื่อเกม ใส่ไอคอนและภาพปก ตั้งค่าเป็นสาธารณะ และแชร์ลิงก์เกมของตัวเองได้
เชื่อมโยงหลักสูตร

คอร์สนี้ฝึก วิทยาการคำนวณ (การคิดเชิงคำนวณ ลำดับขั้นตอน เงื่อนไข การแก้จุดบกพร่อง), การออกแบบและเทคโนโลยี (กระบวนการออกแบบเชิงวิศวกรรม การทำซ้ำเพื่อปรับปรุง) และ ศิลปะ (องค์ประกอบ สี พื้นที่ว่าง)

03 · เตรียมความพร้อม

อุปกรณ์ที่ต้องเตรียม

รายการรายละเอียด
เครื่องคอมพิวเตอร์Windows 10/11 หรือ macOS ต่อเครื่องต่อ 1 คน หรือ 1 คู่ · แนะนำ RAM 8 GB ขึ้นไป · ใช้แท็บเล็ต/โทรศัพท์สร้างไม่ได้ (Roblox Studio ลงได้เฉพาะคอมพิวเตอร์)
เมาส์จำเป็นมาก การหมุนกล้องและจัดวางก้อนใช้ทัชแพดจะลำบาก เตรียมเมาส์แบบมีล้อกลางให้ครบ
อินเทอร์เน็ตต่อเน็ตตลอดคาบ ใช้ล็อกอิน บันทึกงานขึ้นคลาวด์ และเผยแพร่
Roblox Studioดาวน์โหลดฟรีจาก create.roblox.com · ติดตั้งล่วงหน้าทุกเครื่องก่อนคาบ 1 (ไฟล์ ~200 MB + อัปเดต)
บัญชี Robloxคนละ 1 บัญชี · ผู้เรียนอายุต่ำกว่า 13 ปีต้องกรอกวันเกิดจริงเพื่อให้ระบบเปิดโหมดคุ้มครองเด็ก · ต้องมีอีเมลผู้ปกครองยืนยัน (ดูจดหมายถึงผู้ปกครองท้ายเล่ม)
ห้องเรียนโปรเจกเตอร์/จอสำหรับครูสาธิต · แนะนำให้ครูมีเครื่องของตัวเองแยกต่างหาก
ทำก่อนเปิดคอร์ส 1 สัปดาห์

1) ส่งจดหมายขออนุญาตผู้ปกครองและให้กรอกอีเมลยืนยัน   2) ติดตั้ง Roblox Studio ทุกเครื่องแล้วเปิดทดสอบ 1 รอบ   3) สร้างบัญชีให้ทัน หรือให้ผู้ปกครองช่วยสร้างที่บ้าน   4) ทดสอบว่าโรงเรียนไม่บล็อกโดเมน roblox.com และ rbxcdn.com

04 · ต้องรู้ก่อนเริ่ม

ความปลอดภัยและมารยาทออนไลน์

สอนเรื่องนี้ในคาบ 1 และย้ำซ้ำเมื่อถึงคาบเผยแพร่ ถือเป็นส่วนหนึ่งของการให้คะแนน

กติกาบัญชีและความเป็นส่วนตัว

  • ห้ามใส่ข้อมูลส่วนตัว ในชื่อผู้ใช้ ชื่อเกม หรือข้อความในเกม — ไม่มีชื่อจริงเต็ม เบอร์โทร ที่อยู่ โรงเรียน รูปหน้าตัวเอง
  • ตั้งรหัสผ่านที่เดายาก และไม่บอกใครนอกจากผู้ปกครอง — ครูไม่ควรเก็บรหัสผ่านนักเรียนไว้เอง ให้บันทึกไว้ที่ผู้ปกครอง
  • เปิด การยืนยันตัวตนสองชั้น (2-Step Verification) ผ่านอีเมลผู้ปกครองถ้าทำได้
  • ตรวจให้แน่ใจว่าตั้งวันเกิดถูกต้อง ระบบ Roblox จะกรองแชตและจำกัดการติดต่อจากคนแปลกหน้าให้เองสำหรับบัญชีเด็ก

มารยาทเมื่อเผยแพร่และเล่นเกมของเพื่อน

  • เล่นเกมเพื่อนแล้วให้ฟีดแบ็กแบบ "ชม 2 – เสนอ 1": บอกสิ่งที่ชอบ 2 อย่าง และข้อเสนอปรับปรุง 1 อย่าง ด้วยถ้อยคำสุภาพ
  • ห้ามคัดลอกงานเพื่อนมาเผยแพร่เป็นของตัวเอง — เรียนรู้จากกันได้ แต่ต้องมีส่วนที่ออกแบบเอง
  • ถ้าเจอเนื้อหาไม่เหมาะสมในเกมของใคร ให้บอกครูทันที ไม่ตอบโต้เอง
  • เนื้อหาในเกมต้องเหมาะกับทุกวัย: ไม่มีความรุนแรงสมจริง คำหยาบ หรือการพนัน
ข้อกฎหมายที่ครูควรทราบ

Roblox กำหนดอายุขั้นต่ำ 13 ปีสำหรับบางฟีเจอร์ และบังคับใช้แนวปฏิบัติคุ้มครองข้อมูลเด็ก การให้นักเรียนต่ำกว่า 13 ปีสมัครต้องผ่านความยินยอมของผู้ปกครอง โรงเรียนควรเก็บใบยินยอมไว้เป็นหลักฐาน

05 · แผนภาพรวม

ตารางเรียน 8 คาบ

คาบหัวข้อนักเรียนได้อะไรกลับไปสคริปต์
1เปิดโลก Roblox Studioบัญชีพร้อมใช้ + โปรเจกต์เปล่าที่บันทึกขึ้นคลาวด์แล้ว—
2ก้อน Part และการต่อบล็อกแท่นเริ่มต้นและสะพาน 3–4 ก้อนที่จัดวางเป็น—
3พื้นโลกและบรรยากาศภูมิประเทศ + ท้องฟ้า/แสงที่สื่ออารมณ์เกม—
4ทำให้เป็นเกม: เกิด–ตาย–ด่านจุดเกิด + กับดักที่ทำให้ตาย + จุดเซฟด่านKill · Checkpoint
5ออกแบบด่าน Obbyด่านต่อเนื่อง 5–8 จุด เล่นจบได้(นำกลับมาใช้)
6คะแนน เหรียญ และของเก็บกระดานคะแนน + เหรียญเก็บได้เพิ่มแต้มLeaderstats · Coin
7ตกแต่ง เสียง และเทสต์เกมเสียง ข้อความต้อนรับ + บันทึกผลเทสต์กับเพื่อน(ปรับแก้)
8เผยแพร่เกมขึ้นเว็บ Robloxเกมสาธารณะ + ลิงก์ที่แชร์ได้ + ไอคอน/ภาพปก—

ยืดหยุ่นได้: ถ้ามีเวลาน้อย รวมคาบ 3 กับ 5 และให้คาบ 7 เป็นการบ้าน · ถ้ามีเวลาเหลือ เพิ่มคาบพิเศษให้ตกแต่งและอวดผลงาน (Showcase)

Getting into Roblox Studio
50–60 นาทีไม่มีสคริปต์ผลงาน: โปรเจกต์เปล่าบนคลาวด์

จุดประสงค์ — เมื่อจบคาบนักเรียนจะ...

  • ล็อกอินเข้า Roblox Studio ด้วยบัญชีของตัวเองได้
  • บอกชื่อและหน้าที่ของหน้าต่างหลัก 4 อย่าง: Viewport, Explorer, Properties, Toolbox
  • เคลื่อนกล้องด้วย WASD + ลากเมาส์ขวา + ล้อกลาง
  • สร้าง place ใหม่จากเทมเพลต Baseplate และบันทึกขึ้น Roblox (Save to Roblox)

ครูใช้ เตรียมก่อนคาบ & แผนการสอน

เตรียม: ติดตั้ง Roblox Studio ทุกเครื่อง · เปิดโปรแกรมทดสอบล็อกอิน 1 รอบต่อเครื่อง · มีรายชื่อบัญชี/รหัสของนักเรียน (เก็บโดยผู้ปกครอง) · ฉายจอครูได้

แบ่งเวลา:

  1. 0–5 นาที — แนะนำคอร์ส ให้ดูตัวอย่างเกม Obby 1 เกมที่ครูทำไว้ บอกเป้าหมาย "8 คาบ เราจะเผยแพร่เกมของเราเอง"
  2. 5–15 นาที — สอนเรื่อง ความปลอดภัยและมารยาทออนไลน์ ให้นักเรียนช่วยกันตั้งกติกาห้อง เขียนติดผนัง
  3. 15–30 นาที — สาธิต (ดูขั้นตอนด้านล่าง) นักเรียนดูอย่างเดียว ยังไม่แตะเครื่อง
  4. 30–52 นาที — นักเรียนทำตามส่วนของตัวเอง ครูเดินช่วย
  5. 52–60 นาที — เช็กความเข้าใจ + ทุกคนกด Save to Roblox ให้เห็นกับตา

▸ A1 — Kill Brick  ·  วางไว้ ข้างในก้อนกับดัก

local trap = script.Parent

-- เมื่อมีอะไรมาแตะก้อนนี้
trap.Touched:Connect(function(hit)
	local character = hit.Parent
	local humanoid = character:FindFirstChildWhichIsA("Humanoid")
	if humanoid then
		humanoid.Health = 0   -- ทำให้ผู้เล่นตาย แล้ว Roblox จะพาไปเกิดใหม่เอง
	end

▸ A2 — Checkpoints  ·  วางใน ServerScriptService  ·  แป้นเซฟตั้งชื่อ 1, 2, 3… อยู่ในโฟลเดอร์ Checkpoints ใน Workspace

local Players = game:GetService("Players")
local checkpoints = workspace:WaitForChild("Checkpoints")

-- ตอนตัวละครเกิด ให้ย้ายไปที่แป้นเซฟล่าสุดของผู้เล่นคนนั้น
local function onCharacterAdded(character, player)
	local stage = player:GetAttribute("Stage") or 1
	local pad = checkpoints:FindFirstChild(tostring(stage))
	if pad then
		local root = character:WaitForChild("HumanoidRootPart")
		task.wait(0.2)
		root.CFrame = pad.CFrame + Vector3.new(0, 4, 0)
	end
end

local function onPlayerAdded(player)
	player:SetAttribute("Stage", 1)
	player.CharacterAdded:Connect(function(character)
		onCharacterAdded(character, player)
	end)
end

Players.PlayerAdded:Connect(onPlayerAdded)

-- เมื่อผู้เล่นแตะแป้นเซฟ ให้จำเลขด่านไว้ (เฉพาะเลขที่มากกว่าเดิม)
for _, pad in ipairs(checkpoints:GetChildren()) do
	local stageNumber = tonumber(pad.Name)
	if stageNumber then
		pad.Touched:Connect(function(hit)
			local player = Players:GetPlayerFromCharacter(hit.Parent)
			if player then
				local current = player:GetAttribute("Stage") or 1
				if stageNumber > current then
					player:SetAttribute("Stage", stageNumber)
				end
			end
		end)
	end
end

▸ A3 — Leaderstats (กระดานคะแนน Coins)  ·  วางใน ServerScriptService

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	local stats = Instance.new("Folder")
	stats.Name = "leaderstats"      -- ชื่อนี้ห้ามพิมพ์ผิด Roblox ใช้ชื่อนี้โชว์มุมจอ
	stats.Parent = player

	local coins = Instance.new("IntValue")
	coins.Name = "Coins"
	coins.Value = 0
	coins.Parent = stats
end)

▸ A4 — Coin Pickup  ·  วางไว้ ข้างในเหรียญ (เหรียญ: Anchored ✓, CanCollide ✗)

local coin = script.Parent
local Players = game:GetService("Players")

local COIN_VALUE = 1     -- อยากให้เหรียญนี้กี่แต้ม เปลี่ยนเลขนี้
local collected = false  -- กันเก็บซ้ำหลายรอบจากการแตะครั้งเดียว

coin.Touched:Connect(function(hit)
	if collected then return end
	local player = Players:GetPlayerFromCharacter(hit.Parent)
	if not player then return end

	local stats = player:FindFirstChild("leaderstats")
	local coins = stats and stats:FindFirstChild("Coins")
	if coins then
		collected = true
		coins.Value = coins.Value + COIN_VALUE
		coin:Destroy()
	end
end)

▸ A5 — Disappearing Block (ก้อนหายเมื่อเหยียบ)  ·  วางไว้ ข้างในก้อน

local block = script.Parent
local RESET_TIME = 3
local busy = false

block.Touched:Connect(function(hit)
	if busy then return end
	local humanoid = hit.Parent:FindFirstChildWhichIsA("Humanoid")
	if not humanoid then return end

	busy = true
	task.wait(0.5)
	block.Transparency = 0.6
	block.CanCollide = false
	task.wait(RESET_TIME)
	block.Transparency = 0
	block.CanCollide = true
	busy = false
end)

เรียน ท่านผู้ปกครอง

สิ่งที่ต้องขอความร่วมมือ

  • อนุญาตให้บุตรหลานมี/ใช้บัญชี Roblox เพื่อการเรียน โดยกรอกวันเดือนปีเกิดจริง เพื่อให้ระบบเปิดโหมดคุ้มครองผู้เยาว์ (กรองแชต จำกัดการติดต่อจากบุคคลภายนอก)
  • ใช้อีเมลของผู้ปกครองในการยืนยันบัญชี และช่วยเปิดการยืนยันตัวตนสองชั้นหากทำได้
  • เก็บรหัสผ่านไว้กับผู้ปกครอง ไม่เปิดเผยแก่ผู้อื่น
  • รับทราบว่าผลงานเกมของนักเรียนอาจถูกตั้งค่าเป็นสาธารณะบน Roblox โดยไม่มีการเปิดเผยข้อมูลส่วนตัวของนักเรียน (ไม่ใช้ชื่อจริง รูปถ่าย ที่อยู่ หรือชื่อโรงเรียนในเกม)
