⚠️ กฎเหล็ก 3 ข้อ

1) ห้ามใส่ข้อมูลส่วนตัว — ชื่อจริงเต็ม เบอร์โทร ที่อยู่ โรงเรียน รูปหน้า ห้ามอยู่ในชื่อผู้ใช้ ชื่อเกม หรือข้อความในเกม
2) เซฟทุกครั้งก่อนเลิกคาบ ด้วย File ▸ Save to Roblox — กด Play เฉย ๆ ไม่ใช่การเซฟ
3) พูดกับเพื่อนดี ๆ เวลาติเกมเพื่อน ให้ "ชม 2 อย่าง เสนอปรับปรุง 1 อย่าง"

แผนที่หน้าจอ Roblox Studio

การบังคับกล้อง

เครื่องมือจัดก้อน 3 อัน

คำวิเศษ: Anchored

1

เปิดโลก Roblox StudioGetting into Roblox Studio

วันนี้เราจะสร้าง: บัญชีที่พร้อมใช้ และโปรเจกต์เกมเปล่า ๆ ที่เซฟไว้บนคลาวด์แล้ว 1 อัน

  1. เปิดโปรแกรม Roblox Studio (ไม่ใช่แอปที่ใช้เล่นเกม) แล้วล็อกอินด้วยบัญชีของฉัน

  2. หน้าแรกเลือก New แล้วเลือกแม่แบบ Baseplate — จะได้พื้นเปล่ากับท้องฟ้า

  3. เปิดหน้า แผนที่หน้าจอ มาเทียบ แล้วชี้ให้เพื่อนข้าง ๆ ดูว่า Toolbar, Viewport, Explorer, Properties อยู่ตรงไหนบนจอ

  4. ฝึกกล้อง: กด E ค้างบินขึ้นสูง ๆ จนมองลงมาเห็นพื้นทั้งแผ่น แล้วคลิก Baseplate ใน Explorer กด F ให้กล้องพุ่งกลับมา

  5. คลิก Baseplate ใน Explorer แล้วดูหน้าต่าง Properties ว่ามีค่าอะไรโผล่มาบ้าง (Size, Color, Material…)

  6. เมนู File ▸ Save to Roblox ตั้งชื่อเกมว่า "Obby ของ ______" ใส่คำอธิบายสั้น ๆ แล้วกด Create

💡 เกร็ดน่ารู้

Save to Roblox คือการเซฟขึ้น "คลาวด์" ของ Roblox ไม่ใช่เซฟลงเครื่อง แปลว่าเปิดเครื่องไหนก็ทำงานต่อได้ และงานไม่หายถ้าเครื่องพัง

⚠️ ระวัง

ถ้าล็อกอินวนไม่เข้า ให้เปิดเว็บ create.roblox.com ล็อกอินที่นั่นก่อน แล้วค่อยกลับมาเปิด Studio · ถ้ายังไม่ได้ให้ยกมือเรียกครู

🧩 ลองเอง

ใน Properties ของ Baseplate เปลี่ยนช่อง Color เป็นสีที่ชอบ และเปลี่ยน Material จาก Plastic เป็นอย่างอื่น สังเกตพื้นเปลี่ยนยังไง แล้ว Save อีกครั้ง

✍️ บันทึกท้ายคาบ

วันนี้สิ่งที่ตื่นเต้นที่สุดคือ ________________________ · สิ่งที่ยังงงคือ ________________________

2

ก้อน Part และการต่อบล็อกBuilding with Parts

วันนี้เราจะสร้าง: แท่นเริ่มต้นของเกม และสะพานหรือบันไดต่อจากแท่น 3–4 ก้อน

  1. เปิดโปรเจกต์ Obby ของฉันกลับมา: File ▸ Open from Roblox

  2. ที่แท็บ Model เปิด Snap to Grid ตั้งเป็น 1 stud — ก้อนจะต่อกันพอดีไม่มีร่อง

  3. คลิก Home ▸ Part จะได้ก้อนสี่เหลี่ยม 1 ก้อนกลางจอ

  4. ใน Properties ตั้ง Size = 12, 1, 12 ทำเป็นแท่นยืน · เลือก Color และ Material · ติ๊ก Anchored ✓

  5. กด Ctrl+D ทำสำเนาก้อน แล้วใช้เครื่องมือ Move ต่อเป็นบันไดหรือสะพาน 3–4 ก้อน — ทุกก้อนต้อง Anchored

  6. ลากเมาส์คลุมเลือกทุกก้อน คลิกขวา ▸ Group (หรือ Ctrl+G) แล้วดับเบิลคลิกชื่อใน Explorer เปลี่ยนเป็น StartArea

  7. กดปุ่ม Play ▶ เดินตัวละครขึ้นบันได ทดสอบว่าขึ้นได้จริง แล้วกด Stop ⏹

  8. File ▸ Save to Roblox

⚠️ ระวัง

ก้อนร่วงหาย หรือตัวละครตกทะลุพื้น = ลืมติ๊ก Anchored · หาก้อนที่เพิ่งสร้างไม่เจอ = คลิกชื่อมันใน Explorer แล้วกด F · เผลอ Scale จนก้อนบางเป็นกระดาษ = พิมพ์ค่า Size ตรง ๆ ใน Properties

🧩 ลองเอง

ทำ "ราวกันตก" สองข้างสะพาน โดยสร้างก้อนบาง ๆ ยาวเท่าสะพาน · หรือทำก้อนลอย 1 ก้อน (Anchored) ให้ต้องกระโดดข้าม 1 ช่อง

✍️ บันทึกท้ายคาบ

ก้อนที่ทำยากที่สุดคือ ________________________ เพราะ ________________________

3

พื้นโลกและบรรยากาศTerrain, sky & mood

วันนี้เราจะสร้าง: พื้นดิน ภูเขา น้ำ และท้องฟ้า ที่ทำให้เกมมี "ธีม" ชัดเจน

  1. เลือกธีมเกมของฉัน แล้วเขียนลงตรงนี้: ________________  (เกาะ / ถ้ำ / อวกาศ / หิมะ / ป่า)

  2. เปิด Terrain Editor (แท็บ Editor หรือปุ่ม Terrain)

  3. เครื่องมือ Add เลือกวัสดุ เช่น Grass แล้วลากในอากาศใต้ด่าน สร้างพื้นดินรองรับด่านทั้งหมด

  4. Sculpt ปั้นเนิน 1 ลูก · ถ้าเข้าธีม กด Sea Level ใส่น้ำทั้งฉาก

  5. Paint เปลี่ยนผิวอย่างน้อย 2 แบบ เช่น ทางเดินเป็น Sand ยอดเขาเป็น Rock

  6. ใน Explorer คลิก Lighting → Properties ตั้ง ClockTime (17 = เย็น, 2 = กลางคืน) และปรับ Brightness

  7. คลิกขวา Lighting ▸ Insert Object ▸ Atmosphere ปรับ Density ให้มีหมอกบาง ๆ

  8. File ▸ Save to Roblox

⚠️ ระวัง

Terrain กลบงานก่อสร้าง = ใช้ Erase ค่อย ๆ เปิดออก หรือ Ctrl+Z · ฉากมืดจนมองไม่เห็น = ตั้ง ClockTime กลับเป็น 14 และเพิ่ม Brightness · เครื่องช้ามาก = ลดขนาด Brush ให้เล็กลง

🧩 ลองเอง

ปั้นภูเขาสูงไว้เป็นฉากหลัง 1 ลูก · หรือขุดถ้ำให้ด่านลอดผ่าน · หรือเปลี่ยน Sky ให้เป็นกลางคืนมีดาว

✍️ บันทึกท้ายคาบ

บรรยากาศที่ฉันอยากให้ผู้เล่นรู้สึกตอนเล่นเกมคือ ________________________

4

ทำให้เป็นเกม: เกิด – ตาย – ด่านSpawn, kill bricks & checkpoints

วันนี้เราจะสร้าง: จุดเกิดของผู้เล่น · กับดักที่แตะแล้วตาย · จุดเซฟด่านที่ทำให้เกิดใหม่ตรงด่านล่าสุด

คาบนี้เริ่มใช้ สคริปต์ แล้ว สคริปต์คือรายการคำสั่งที่คอมพิวเตอร์อ่านจากบนลงล่าง เรา ไม่ต้องเขียนเอง แค่คัดลอกจาก หน้าสคริปต์ มาวางให้ถูกที่ ดูรูปว่าอะไรวางตรงไหน:

  1. Home ▸ Spawn วางบนแท่นเริ่ม · ติ๊ก Anchored · ถ้ามี SpawnLocation ซ้ำให้ลบให้เหลืออันเดียว

  2. สร้าง Part ยาว ๆ เป็นพื้นช่วงอันตราย · ตั้งสี แดง · Material = Neon · เปลี่ยนชื่อใน Explorer เป็น LavaPart

  3. ใน Explorer ชี้ที่ LavaPart กดปุ่ม ➕ เลือก Script · ลบข้อความตัวอย่างทั้งหมด · วาง สคริปต์ A1 · กด Ctrl+S

  4. กด Play ▶ เดินไปเหยียบ LavaPart → ตัวละครต้องตายและเกิดใหม่ที่ Spawn ✓

  5. ที่ Workspace กด ➕ ▸ Folder ตั้งชื่อ Checkpoints

  6. สร้างแป้นเซฟแบน ๆ 3 อัน วางที่ต้นด่านแต่ละช่วง · ลากทั้ง 3 เข้าโฟลเดอร์ Checkpoints · เปลี่ยนชื่อเป็น 1, 2, 3 (อันแรก = จุดเริ่ม)

  7. ที่ ServerScriptService กด ➕ ▸ Script · วาง สคริปต์ A2

  8. กด Play ▶ เดินไปแตะแป้น 2 แล้วจงใจไปเหยียบลาวา → ต้องเกิดใหม่ที่แป้น 2 ไม่ใช่จุดเริ่ม ✓

  9. File ▸ Save to Roblox

💡 เกร็ดน่ารู้

คอมพิวเตอร์อ่านตัวพิมพ์ใหญ่กับพิมพ์เล็กไม่เหมือนกัน Humanoid กับ humanoid คนละคำ พิมพ์ผิดตัวเดียวสคริปต์ก็ไม่ทำงาน เพราะงั้นให้ คัดลอกวาง อย่าพิมพ์เอง

⚠️ ระวัง

เหยียบกับดักแล้วไม่ตาย = สคริปต์อยู่ผิดที่ (ต้องอยู่ ข้างในก้อน) · Checkpoint ไม่จำ = ชื่อแป้นไม่ใช่ตัวเลขล้วน หรือไม่ได้อยู่ในโฟลเดอร์ Checkpoints หรือสคริปต์ A2 ไม่ได้อยู่ใน ServerScriptService · เปิด View ▸ Output ไว้ดูข้อความสีแดง

🧩 ลองเอง

ทำกับดักแบบอื่น: ก้อนหนามโผล่จากพื้น · ช่องว่างให้ตกลงเหว (ทำก้อนกับดักบาง ๆ ไว้ก้นเหว) · กำแพงไฟที่ต้องวิ่งผ่านให้ทันจังหวะ

✍️ บันทึกท้ายคาบ

ตอนสคริปต์ไม่ทำงาน ฉันหาสาเหตุและแก้ยังไง ________________________

5

ออกแบบด่าน ObbyDesigning a playable obby

วันนี้เราจะสร้าง: ด่านต่อเนื่อง 5–8 ช่วง ที่เล่นจบได้จริง ยากขึ้นเรื่อย ๆ แต่ไม่ทำให้ผู้เล่นหงุดหงิด

  1. วาดแผนด่านบนกระดาษก่อน: ช่วงที่ 1 ถึง ___ และจดว่าแต่ละช่วง "ยากเรื่องอะไร"

  2. สร้างด่านให้ครบอย่างน้อย 5 ช่วง ต่อเนื่องจากแท่นเริ่ม

  3. ช่วงแรก ต้องง่ายมาก ผ่านได้ในไม่กี่วินาที ให้ผู้เล่นรู้สึกว่า "ทำได้"

  4. เพิ่มความยาก ทีละอย่าง — ช่วงนี้ช่องกว้างขึ้น ช่วงหน้าค่อยเพิ่มก้อนแคบ อย่าใส่พร้อมกันหมด

  5. ใส่ จุดพัก พื้นกว้าง ๆ ปลอดภัย อย่างน้อย 1 จุด หลังช่วงที่ยาก

  6. วางแป้นเซฟก่อนทุกช่วงยาก ตั้งเลขเรียง 1 → n ไม่ซ้ำกัน

  7. ใช้อุปสรรคอย่างน้อย 3 แบบต่างกัน (กระโดดข้าม / เดินก้อนแคบ / ลอดใต้ / หลบกับดัก)

  8. ทำแป้น FINISH สีทองใหญ่ ๆ ไว้ท้ายด่าน

  9. เดินทดสอบตั้งแต่ต้นจนจบ ให้ ผ่านได้ทุกช่วงด้วยตัวเอง

  10. File ▸ Save to Roblox

⚠️ ระวัง

ด่านยากจนตัวเองยังผ่านไม่ได้ = ลดระยะกระโดด เพิ่มขนาดก้อน · ด่านยาวแต่ราบเรียบน่าเบื่อ = สลับประเภทอุปสรรค · แป้นเซฟเลขซ้ำ = checkpoint จะสับสน ให้ไล่เลขใหม่

🧩 ลองเอง

เพิ่มทางลับ (shortcut) ที่ยากมากแต่ข้ามได้ 2 ช่วง · หรือทำก้อนที่หายตอนเหยียบ โดยใส่ สคริปต์ A5 ไว้ข้างในก้อน

✍️ บันทึกท้ายคาบ

ช่วงที่ฉันคิดว่าสนุกที่สุดคือช่วง ______ เพราะ ________________________

6

คะแนน เหรียญ และของเก็บLeaderboard, coins & pickups

วันนี้เราจะสร้าง: กระดานคะแนนมุมจอ และเหรียญที่เดินชนแล้วหาย พร้อมบวกแต้มให้ผู้เล่น

  1. ที่ ServerScriptService กด ➕ ▸ Script วาง สคริปต์ A3 → กด Play เห็นกล่อง Coins มุมขวาบน

  2. ทำเหรียญต้นแบบ: Part ทรงกระบอกบาง ๆ สีทอง Material Neon ตั้งชื่อ Coin · ติ๊ก Anchored ✓ · ปิด CanCollide ✗ (เดินทะลุได้ ไม่สะดุด)

  3. ใส่ Script ไว้ ข้างในเหรียญ แล้ววาง สคริปต์ A4

  4. กด Play เดินชนเหรียญ 1 อัน → เลข Coins เพิ่มเป็น 1 และเหรียญหายไป ✓

  5. ทำสำเนาเหรียญ (จากอันที่มีสคริปต์แล้ว) ด้วย Ctrl+D วางกระจายตามด่านอย่างน้อย 8 อัน

  6. วางเหรียญกลุ่มหนึ่งไว้ในที่ เก็บยาก (ต้องเสี่ยงกระโดดไปเอา) เป็นรางวัลของความกล้า

  7. File ▸ Save to Roblox

⚠️ ระวัง

ไม่มีกล่องคะแนนโผล่ = สคริปต์ A3 ไม่ได้อยู่ใน ServerScriptService หรือคำว่า leaderstats พิมพ์ผิด · เก็บเหรียญแล้วไม่บวก = เหรียญที่ก๊อปมาไม่มีสคริปต์ (ต้องก๊อปจากอันที่ มีสคริปต์แล้ว) · เดินสะดุดเหรียญ = ยังเปิด CanCollide อยู่

🧩 ลองเอง

ใส่ สคริปต์ A6 ให้เหรียญหมุนช้า ๆ · หรือทำ "เหรียญเพชร" สีฟ้าที่ให้ 5 แต้ม โดยแก้เลข COIN_VALUE = 1 ในสคริปต์ A4 เป็น 5

✍️ บันทึกท้ายคาบ

ฉันวางเหรียญที่เก็บยากไว้ตรงไหน และทำไมถึงเลือกตรงนั้น ________________________

วันนี้เราจะสร้าง: เสียงและป้ายข้อความในเกม แล้วให้เพื่อนช่วยเทสต์ จดปัญหา และแก้ให้ได้อย่างน้อย 3 อย่าง

  1. ใส่เสียงบรรยากาศ: ใน Explorer เลือก SoundService กด ➕ ▸ Sound → ในช่อง SoundId กดค้นเพลงที่ใช้ได้ฟรี → ติ๊ก Looped และ Playing

  2. ใส่ป้ายข้อความอย่างน้อย 3 ป้าย: ใช้ Toolbox ค้นคำว่า "sign" เลือกโมเดลป้าย แล้วแก้ข้อความเป็น "START", "ระวังลาวา!", "FINISH"

  3. เก็บกวาด: ลบก้อนทดลองที่ไม่ใช้แล้ว · ตรวจให้แน่ใจว่าทุกก้อน Anchored

  4. ให้เพื่อน 1 คนเล่นเกมของฉัน — ฉันนั่งดูเงียบ ๆ ห้ามบอกทาง จดทุกจุดที่เพื่อนติดลงตารางด้านล่าง

  5. ไปเล่นเกมเพื่อน แล้วให้ฟีดแบ็กแบบ "ชม 2 อย่าง – เสนอปรับปรุง 1 อย่าง" ด้วยคำพูดสุภาพ

  6. เลือก 3 อย่าง ที่ผู้เล่นติดบ่อยที่สุด แล้วแก้ให้เสร็จในคาบนี้

  7. File ▸ Save to Roblox

⚠️ ระวัง

เพลงไม่ดัง = ยังไม่ติ๊ก Playing หรือ SoundId ว่าง หรือเสียงนั้นใช้ไม่ได้ · อยากแก้ทุกอย่างพร้อมกัน = เลือกแค่ 3 อย่างที่คนติดบ่อยสุด · Save ก่อนแก้ทุกครั้ง จะได้ย้อนกลับได้ถ้าพัง

💡 เกร็ดน่ารู้

เจ้าของเกมห้ามบอกทางตอนเพื่อนเทสต์ เพราะเราอยากรู้ว่า "คนที่ไม่เคยเล่น" จะงงตรงไหน — ตรงที่เพื่อนงง คือตรงที่ต้องเพิ่มป้ายหรือทำให้ชัดขึ้น

เผยแพร่เกมขึ้นเว็บ RobloxPublish & go public

วันนี้เราจะทำ: ตั้งค่าเกม ใส่ไอคอนและภาพปก เปลี่ยนเกมเป็นสาธารณะ และได้ลิงก์เกมของตัวเองไปแชร์

  1. เตรียมรูป ไอคอนเกม 1 รูป (จับภาพหน้าจอเกมสวย ๆ ด้วย PrtSc / ⌘+⇧+4 หรือวาดเอง — เป็นรูปจัตุรัส) และภาพปกกว้างอีก 1 รูป

  2. File ▸ Publish to Roblox เพื่ออัปเดตเกมเป็นเวอร์ชันล่าสุด

  3. Home ▸ Game Settings ▸ Basic Info: ตรวจชื่อเกมและคำอธิบาย (⚠️ ห้ามมีข้อมูลส่วนตัว) · เลือก Genre เป็น Obby หรือ Adventure

  4. Game Settings ▸ Places: อัปโหลด Icon (รูปจัตุรัส) และ Thumbnail (รูปกว้าง)

  5. ตั้งสถานะเกมเป็น Public แล้วกด Save · ถ้าปุ่มเป็นสีเทากดไม่ได้ ให้เลือก Friends ไปก่อน หรือขอครูช่วย

  6. เปิดเว็บ create.roblox.com ▸ Creations → คลิกเกมของฉัน → ปุ่ม ⋯ ▸ Copy Link

  7. เปิดลิงก์ในแท็บใหม่ ทดสอบว่าเล่นเกมผ่านเว็บได้จริง

  8. วางลิงก์ในที่รวมงานของห้อง และเขียนลงหน้า "เกมของฉัน" ท้ายเล่ม

  9. เล่นเกมเพื่อนอย่างน้อย 3 เกม กดถูกใจ และให้ฟีดแบ็กสุภาพ

⚠️ ระวัง

กด Publish แล้วไม่ขึ้น = ยังไม่ล็อกอิน / เน็ตหลุด / ชื่อเกมว่าง · ตั้ง Public ไม่ได้ (ปุ่มเทา) = ต้องยืนยันอีเมลผู้ปกครองในบัญชีก่อน หรือใช้ Friends ไปก่อน · เพื่อนเปิดลิงก์แล้วเข้าไม่ได้ = รอ 2–3 นาทีให้ระบบประมวลผลหลังเผยแพร่ครั้งแรก

💡 "Public" แปลว่าอะไร

เกมของเราจะขึ้นบนเว็บ Roblox และ ใครก็เข้ามาเล่นได้ เพราะงั้นเนื้อหาในเกมต้องเหมาะกับทุกวัย และต้องไม่มีข้อมูลส่วนตัวของเรา ถ้าอยากให้เฉพาะเพื่อนเล่น ให้ตั้งเป็น Friends แทน

★

หน้าจอโหลดเกมแบบกำหนดเองCustom Loading Screen (ภารกิจพิเศษ)

วันนี้เราจะทำ: ปิดหน้าจอโหลดแบบเดิมของ Roblox แล้วสร้างหน้าจอโหลดของตัวเอง มีแถบความคืบหน้า (progress bar) กับตัวเลข % ที่ค่อย ๆ วิ่งจนครบ แล้วจางหายเข้าสู่เกม
💡 ทำไมต้องมีหน้าจอโหลด

ปกติตอนเปิดเกม Roblox จะโชว์วงกลมหมุน ๆ ให้เองอัตโนมัติ แต่ถ้าอยากให้เกมมีสไตล์ของตัวเอง เช่น ใส่โลโก้ ใส่แถบเปอร์เซ็นต์ หรือใส่คำแนะนำการเล่นระหว่างรอ เราต้อง ปิดของเดิมแล้วสร้างใหม่เอง

โครงสร้างที่ต้องสร้างใน Explorer

  1. ใน Explorer ชี้ที่ ReplicatedFirst → กด ➕ → เลือก ScreenGui → เปลี่ยนชื่อเป็น LoadingScreen

  2. ชี้ที่ LoadingScreen → ➕ ▸ Frame → ตั้งชื่อ Background → ใน Properties ตั้ง Size = {1,0},{1,0}, Position = {0,0},{0,0}, BackgroundColor3 เป็นสีเข้ม (เช่น เกือบดำ)

  3. ชี้ที่ Background → ➕ ▸ Frame → ตั้งชื่อ Bar (นี่คือ "ราง" ของแถบ) → ตั้ง Size เป็นแถบยาวบาง ๆ เช่น {0.5,0},{0,24} วางกึ่งกลางจอ → สีเทาเข้ม

  4. ชี้ที่ Bar → ➕ ▸ Frame → ตั้งชื่อ Fill (ส่วนที่จะ "วิ่ง") → ตั้ง Size เริ่มต้นเป็น {0,0},{1,0} → เลือกสีสว่างหรือสีธีมเกม

  5. ชี้ที่ Background → ➕ ▸ TextLabel → ตั้งชื่อ Percent → ลบข้อความตัวอย่าง พิมพ์ 0% → ตั้ง BackgroundTransparency = 1 (โปร่งใส) วางไว้ใต้แถบ

  6. ชี้ที่ LoadingScreen → ➕ ▸ LocalScript → ลบข้อความตัวอย่าง → วางสคริปต์ A8 · Custom Loading Screen จากคลังสคริปต์ท้ายเล่ม

  7. กด Ctrl+S แล้วกด Play ทดสอบดู — ถ้าเกมโหลดเร็วเกินจนมองแถบไม่ทัน ให้ลองกด Publish แล้วเข้าเล่นผ่านเว็บจริงแทน จะเห็นแถบวิ่งชัดกว่า

🧩 ลองเอง

1) เปลี่ยนสี Fill ให้เข้ากับธีมเกมของตัวเอง หรือทำให้เป็นไล่สี (Gradient) ด้วย UIGradient
2) ใส่ UICorner ให้ Bar และ Fill เพื่อให้ขอบโค้งมนสวยขึ้น
3) เพิ่ม TextLabel อีกอันบอกชื่อเกมหรือคำแนะนำการเล่น เช่น "กด Space เพื่อกระโดด"

⚠️ ระวัง

สคริปต์ต้องเป็น LocalScript ไม่ใช่ Script ธรรมดา (เพราะหน้าจอเป็นเรื่องของแต่ละเครื่องผู้เล่น) · ต้องวางไว้ใน ReplicatedFirst เท่านั้น ถ้าวางที่อื่นจะโผล่ช้าเกินไปจนมองไม่ทันตอนโหลด · ถ้าจอค้างที่ 0% ตลอด ให้เช็กว่าพิมพ์ชื่อ Background/Bar/Fill/Percent ตรงกับในสคริปต์ทุกตัวอักษร

A2 · Checkpoints — วางใน ServerScriptService (ใช้คาบ 4)

local Players = game:GetService("Players")
local checkpoints = workspace:WaitForChild("Checkpoints")

local function onCharacterAdded(character, player)
	local stage = player:GetAttribute("Stage") or 1
	local pad = checkpoints:FindFirstChild(tostring(stage))
	if pad then
		local root = character:WaitForChild("HumanoidRootPart")
		task.wait(0.2)
		root.CFrame = pad.CFrame + Vector3.new(0, 4, 0)
	end
end

Players.PlayerAdded:Connect(function(player)
	player:SetAttribute("Stage", 1)
	player.CharacterAdded:Connect(function(character)
		onCharacterAdded(character, player)
	end)
end)

for _, pad in ipairs(checkpoints:GetChildren()) do
	local stageNumber = tonumber(pad.Name)
	if stageNumber then
		pad.Touched:Connect(function(hit)
			local player = Players:GetPlayerFromCharacter(hit.Parent)
			if player then
				local current = player:GetAttribute("Stage") or 1
				if stageNumber > current then
					player:SetAttribute("Stage", stageNumber)
				end
			end
		end)
	end
end

A4 · Coin Pickup — วางไว้ "ข้างในเหรียญ" (ใช้คาบ 6)

local coin = script.Parent
local Players = game:GetService("Players")

local COIN_VALUE = 1
local collected = false

coin.Touched:Connect(function(hit)
	if collected then return end
	local player = Players:GetPlayerFromCharacter(hit.Parent)
	if not player then return end

	local stats = player:FindFirstChild("leaderstats")
	local coins = stats and stats:FindFirstChild("Coins")
	if coins then
		collected = true
		coins.Value = coins.Value + COIN_VALUE
		coin:Destroy()
	end
end)

A5 · Disappearing Block (ก้อนหายเมื่อเหยียบ) — วางไว้ "ข้างในก้อน" (ลองเอง คาบ 5)

local block = script.Parent
local RESET_TIME = 3
local busy = false

block.Touched:Connect(function(hit)
	if busy then return end
	local humanoid = hit.Parent:FindFirstChildWhichIsA("Humanoid")
	if not humanoid then return end

	busy = true
	task.wait(0.5)
	block.Transparency = 0.6
	block.CanCollide = false
	task.wait(RESET_TIME)
	block.Transparency = 0
	block.CanCollide = true
	busy = false
end)

A7 · Finish Line (เส้นชัยมีเสียง + บวก 10 แต้ม) — วางไว้ "ข้างในก้อน FINISH" (โบนัส)

local finish = script.Parent
local sound = finish:FindFirstChildWhichIsA("Sound")
local Players = game:GetService("Players")
local won = {}

finish.Touched:Connect(function(hit)
	local player = Players:GetPlayerFromCharacter(hit.Parent)
	if not player or won[player] then return end
	won[player] = true

	if sound then
		sound:Play()
	end

	local stats = player:FindFirstChild("leaderstats")
	local coins = stats and stats:FindFirstChild("Coins")
	if coins then
		coins.Value = coins.Value + 10
	end

	task.wait(3)
	won[player] = nil
end)

A8 · Custom Loading Screen — วางเป็น "LocalScript ข้างใน ScreenGui LoadingScreen" ที่ ReplicatedFirst (ภารกิจพิเศษ)

local ReplicatedFirst = game:GetService("ReplicatedFirst")
local ContentProvider = game:GetService("ContentProvider")

local screenGui = script.Parent
local fill = screenGui.Background.Bar.Fill
local percentLabel = screenGui.Background.Percent

-- ปิดหน้าจอโหลดเริ่มต้นของ Roblox เพื่อใช้หน้าจอที่เราออกแบบเองแทน
ReplicatedFirst:RemoveDefaultLoadingScreen()

local assets = game:GetDescendants()
local total = #assets
local loaded = 0

-- โหลดของทีละชิ้น แล้วอัปเดตแถบกับตัวเลข % ทุกครั้งที่โหลดเสร็จ 1 ชิ้น
for _, asset in ipairs(assets) do
	task.spawn(function()
		pcall(function()
			ContentProvider:PreloadAsync({ asset })
		end)
		loaded += 1
		local percent = math.floor((loaded / total) * 100)
		fill.Size = UDim2.new(percent / 100, 0, 1, 0)
		percentLabel.Text = percent .. "%"
	end)
end

repeat task.wait() until loaded >= total

-- โหลดครบแล้ว หน่วงนิดหน่อยให้เห็น 100% เต็ม ๆ แล้วค่อย ๆ จางหายไป
task.wait(0.3)
for i = 1, 10 do
	screenGui.Background.BackgroundTransparency += 0.1
	fill.BackgroundTransparency += 0.1
	percentLabel.TextTransparency += 0.1
	task.wait(0.03)
end
screenGui:Destroy()
